# Icon with the "stat" wordmark — archived 2026-08-09

The original launcher icon, carrying "B" over the word **stat**. Kept because the
decision to drop the word is reversible: if "BullDozer Stats" ever comes back as
the product name, this is the matching mark.

Why it was replaced: the app is called BullDozer everywhere now (launcher label,
both store listings), so the icon was the last place still saying "Stats". At the
60pt a home screen actually renders, the word is an unreadable smudge — Apple's
guidance is to keep text out of icons for exactly that reason.

Files are the flutter_launcher_icons inputs: icon.png (master 1024), plus the
Android adaptive pair icon_background.png / icon_foreground.png. To restore:
copy them back over assets/icon/ and run `dart run flutter_launcher_icons`.
